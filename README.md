# Notes App

Консольное приложение для управления заметками.

## User Stories
1. Как пользователь, я хочу создавать заметку с заголовком и текстом, чтобы сохранять свои мысли.
2. Как пользователь, я хочу удалять и редактировать заметки.
3. Как пользователь, я хочу присваивать заметкам категории, чтобы структурировать их.
4. Как пользователь, я хочу искать заметки по тексту или заголовку.

## MVP (Minimum Viable Product)
Консольное приложение, поддерживающее CRUD-операции для заметок, хранение данных в локальной SQLite базе и фильтрацию по текстовому запросу.

## Архитектура
* **Данные**: SQLite (файл `notes.db`). Таблица `notes` (id, title, content, category).
* **Логика**: Класс `NotesManager` инкапсулирует все SQL-запросы.
* **Интерфейс**: Консольное меню в `main.py`, взаимодействующее только с `NotesManager`.

## Запуск
1. Установить зависимости не требуется (используются встроенные библиотеки).
2. Запуск приложения: `python main.py`
3. Запуск тестов: `pytest tests/ --cov=notes_manager`
