# Финальный отчёт и Ретроспектива

## Путь по этапам
Проект был начат с формирования структуры данных в SQLite. Затем, следуя TDD, были написаны падающие тесты для базовых CRUD операций, после чего реализован класс `NotesManager`. После покрытия логики тестами был добавлен консольный интерфейс. На этапе поддержки были отработаны баги, связанные с регистром текста и валидацией ввода.
