# Чек-лист приёмочного тестирования

- [x] 1. Приложение запускается без ошибок.
- [x] 2. Создание заметки с корректными данными проходит успешно.
- [x] 3. Попытка создать заметку с пустым заголовком выдает ошибку.
- [x] 4. Вывод всех заметок отображает только что созданную заметку.
- [x] 5. Редактирование существующей заметки успешно обновляет данные.
- [x] 6. Попытка редактировать несуществующий ID обрабатывается корректно (ничего не падает).
- [x] 7. Удаление заметки по ID убирает её из списка.
- [x] 8. Попытка удаления несуществующей заметки обрабатывается корректно.
- [x] 9. Поиск по существующему слову в заголовке возвращает нужную заметку.
- [x] 10. Поиск по существующему слову в тексте возвращает нужную заметку.
- [x] 11. Поиск нечувствителен к регистру (Apple == apple).
- [x] 12. Фильтрация по категории возвращает только заметки указанной категории.
- [x] 13. Фильтрация по категории нечувствительна к регистру.
- [x] 14. Функция просмотра всех доступных категорий работает без дубликатов.
